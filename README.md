# 🏡 STUDY HOME

STUDY HOME — гра для Telegram, у якій можна вивчати правила дорожнього руху України та облаштовувати власний віртуальний будинок.

## 🎮 Можливості

- 📚 Проходити тести з ПДР України
- 🪙 Заробляти монетки за правильні відповіді
- 🏠 Купувати меблі та прикрашати кімнати
- ⭐ Отримувати досвід і підвищувати рівень
- 🎁 Виконувати щоденні завдання

## 🎨 Дизайн

Затишний пастельний стиль, милі меблі та зручний інтерфейс для смартфонів.

## 🚀 Статус

Проєкт на початковому етапі розробки.
